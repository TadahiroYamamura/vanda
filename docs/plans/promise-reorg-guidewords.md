# 約束リストの作り直し: 損失を洗い出すガイドワードの草案

PO が直すためのたたき台。約束の抜けを見つけるために、「当てる対象」の 1 つずつにガイドワードを順に当て、「そうなったら誰が何を失うか」を書き出す。約束リストと規則はまだ変えない。

- 「損失」は、約束が破れた時に誰かが失うもの。約束リストの用語にはまだない
- 損失の種類は、`.claude/rules/promises.md` の 3 つの正しさに対応する

## 1. 損失の種類

| 正しさ | 損なわれると起きること |
|---|---|
| 目的的 | 使う人の課題が解決されない |
| 機能的 | 出力や記録が壊れる、間違う |
| 規範的 | ルールや法律に違反する、第三者に損失が出る |

## 2. ガイドワード

| 正しさ | 当てる対象 | ガイドワード | 借りた元 |
|---|---|---|---|
| 機能的 | 指示（例: 承認する、取り消す、チェックを通す） | 出ない／出て害になる／早すぎる・遅すぎる・順序が違う／途中で止まる・残り続ける | STPA |
| 機能的 | 戻ってくる情報とデータ（例: 画面の表示、承認の記録） | 欠ける／重複する／古い／食い違う／別のものを指す | HAZOP |
| 目的的 | 人 × したいこと | できない／遅い／読み違える／信じられず自分で確かめ直す／量が多くて素通しする／やり直せない | なし（この草案で作った） |
| 規範的 | 境界を越えるもの（例: リクエスト、トークン、記録） | なりすます／書き換える／やっていないと言える／漏れる／止められる／権限を越える | STRIDE |
| 規範的 | 外の取り決め（`docs/formats.md`） | 取り決めどおりで動かない／取り決めにないものを受け入れる／黙って変わる | なし（この草案で作った） |

## 3. 使い方

1. 当てる対象を並べる（指示、戻ってくる情報、人としたいこと、境界を越えるもの、外の取り決め）
2. 対象を行、ガイドワードを列にした表を作り、マスごとに「そうなった形」を書く。当てはまらないマスには、当てはまらない理由を書く。空のままにしない
3. マスごとに、受け皿になる約束を書く。受け皿のないマスが、約束の抜けの候補になる
4. 抜けの候補ごとに、約束を足すか、関知しないかを PO が決める

## 4. 試した例: 指示「承認する」

受け皿は `promise-reorg-upper-claims.md` の上の側の約束。

| ガイドワード | そうなった形 | 受け皿 |
|---|---|---|
| 出ない | 承認したのに記録されない | `agreement-history-kept` |
| 出て害になる | 見ていない中身に承認が付く | `agreement-follows-content` |
| 遅すぎる | 中身が変わった後に、古い画面から承認する | `agreement-follows-content` |
| 残り続ける | 中身が変わっても承認済のまま | `agreement-follows-content` |
| 途中で止まる | 記録が半分だけ書かれる | `agreement-keeps-files-safe` |
| なりすます | PO でない人や AI が、PO の名前で承認する | ない |
| 量が多くて素通しする | PO が読まずに承認する | ない |

## 5. 分かっている限界

- ガイドワードは、並べた対象についての抜けしか見つけない。対象そのものの抜け（並べ忘れた指示・人・境界）は見つからない
- 目的的と外の取り決めのガイドワードは、定番のものがなく、この草案で作った。使いながら足す・直す
- STPA・HAZOP・STRIDE のガイドワードは記憶から書いた。決める前に元の資料で確かめる
