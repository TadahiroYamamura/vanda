# vanda 段 2 のテストの計画（テスト担当向け）

この計画は、vanda の段 2 のテストを書くテスト担当のエージェントに渡す。テスト担当は、実装のコードを書き換えない。実装を読んで期待値を作らない（読んでよいのは、公開の関数の名前・引数・戻り値の型とそのコメント、API の形、`docs/formats.md`）。

前提として読むもの: `CLAUDE.md`、`docs/spec.md`、`docs/terms.md`、`docs/formats.md`、`docs/plans/stage2-impl.md` の「段 2 で作るもの」と「作る部品」。

## テストの決まり

段 1 と同じ（`docs/plans/stage1-test.md` の「テストの決まり」）。加えて:

- 無作為に入力を作るテストは、種を固定しない。実行のたびに変え、使った種を記録に出し、環境の変数でだけ固定する
- 一時的な git のリポジトリやファイルは、テストごとの一時ディレクトリに作る。決まった場所に書かない
- E2E のテストは、一時的な git のリポジトリに対して `vanda serve` を動かし、ブラウザで操作する。本物の GitHub には繋がない（ストーリーの置き場所は、テストの中の偽の HTTP サーバーか、外部のコマンドのアダプタで差し替える）

## テストの種類

| 種類 | 使う所 | 道具 |
|---|---|---|
| API のテスト | 一覧・差分・合意・約束の詳細の中身（判定はサーバーにあるので、ここが主） | Go の `testing`（`httptest`）と、一時的な git のリポジトリ |
| ランダムチェック | RV-01 の「漏れも重複もない」 | `rapid` |
| 画面の部品のテスト | 画面が API の結果を正しく見せるか（フラグ、状態、変更前と変更後、たたむ、TLA+ の記号とコピー） | Vitest、Testing Library、MSW |
| E2E のテスト | ストーリーを選んで、一覧を見て、合意して、審査が通るまでの流れ | Playwright（Chrome） |

## 確かめること

### RV-01 の一覧（API）

| 確かめること |
|---|
| 追加・変更・削除・名前の変更のそれぞれが、一覧に 1 度ずつ出る |
| 変わっていないものは出ない |
| 約束の文が変わらず、シナリオのファイルだけが変わったものも出る |
| 書き方だけの違い（項目の順、空白）は、変わったものとして出ない |
| ブランチごとの見方は、ベースブランチと分かれた点との差分。ベースブランチを変えると、一覧も変わる |
| ストーリー全体の見方は、ストーリーで最初に変える直前の中身と今の中身。途中で足して後で消したものは出ない。ほかのストーリーが途中で同じものを変えていたら示す |
| 外れた合意（RV-14）が示される |

### RV-01 のランダムチェック

無作為に、約束・用語・機能・シナリオのファイルを足す・変える・消す・名前を変える操作の列を作り、git のリポジトリに当てる。一覧が、テストの中で別に数えた「変わったものの集まり」と、ちょうど一致する（漏れも重複もない）ことを確かめる。

### 合意する（RV-06。API と E2E）

| 確かめること |
|---|
| 合意すると、合意の記録が 1 件増え、その約束のフラグが外れ、1 つのコミットになる |
| コミットのメッセージにストーリーの ID があり、段 1 の由来の審査が通る |
| 合意した後、段 1 の合意の審査で、その約束は合意済になる |
| フラグを外しても、約束リストのほかの行（コメント、空行、順）は変わらない |
| 作業ツリーにある、合意と関係のない書きかけの変更は、コミットに入らない |
| 合意で変えるファイルに書きかけの変更があるときは、合意を断り、理由が出る |
| `user.name` か `user.email` がないときは、合意できず、理由が出る |
| ファイル（シナリオなど）にも合意できる |

### 約束の詳細（API と画面の部品）

| 確かめること |
|---|
| エビデンスがタイプごとに出る（シナリオは本文、TLA+ は該当する定義、ガードレールは定義のファイル、Go のテストは名前と場所） |
| 由来に、約束を作り・変えたコミットとストーリーの ID が出る |
| 合意の履歴に、その約束への合意が出て、今の中身に合うかが分かる |
| TLA+ は数学の記号で見せ、コピーするとリポジトリの文字のまま（置き換えの表の全部の記号を回す） |

### ストーリーの置き場所（API）

| 確かめること |
|---|
| 題・本文・添付ファイルへのリンクを読める（偽の HTTP サーバーで） |
| 認証の誤り、ネットワークの誤り、ないストーリーで、理由が画面に出る（黙って空にしない） |

### E2E（Playwright）

| 確かめること |
|---|
| ストーリーを選び、一覧を見て、全部に合意すると、`vanda check` の合意の審査が通る |
| 合意した約束を変えると、一覧に「差分あり」として戻る |
| ベースブランチと見方の切り替え |
