# 約束リストの作り直し: 性質にガイドワードを当てた分析

機能のある 8 つの性質（A-1、A-2、A-3、A-4、B-2、C、D-1、D-2）に、性質向けのガイドワードを当て、逸脱の形ごとに対策があるかを見た。約束リストはまだ変えない。

- 定義は `promise-reorg-properties.md` の 5 章、ガイドワードと A-2 の表は `promise-reorg-deviation-trial.md`
- 古い形の分析（制御図の行にガイドワードを当てたもの）は `promise-reorg-analysis-owner.md`。G1〜G12 は、そこの抜けの番号
- 対策があるかは、今の約束リストの文と設定を読んで付けた。コードや実物で確かめたものは、行にそう書いた

## 1. 結論

- 答責性の実現度は、今は 0。逸脱の形 111 のうち、4 つの条件がすべて揃うものがない。「約束リストに戻せる」の対策が、8 つの性質のどれにもないため（B-3 の上向きの経路が、まだない）
- 定義は変えず、0 のまま見せる。見つかった逸脱を約束リストに戻す経路がなければ、同じ逸脱を次に防げないので、0 は今の状態を表している。B-3 の上向きの経路ができるまで、進みは条件ごとの内訳で見る
- 条件ごとに見ると、「早く検知される」に対策がある形が 26、「被害が致命的にならない」に対策がある形が 24（どちらも 111 のうち）
- 新しい抜けの候補が 34 行出た（同じ形が 2 つの性質に出たものを除くと 31）。最も多く見つけたガイドワードは「対象から外れている」
- G1〜G12 は、すべてどこかの性質に出た。ただし、書いた行為者（開発者（AI））は G1〜G12 を知っていたので、「この方法で見つけ直せる」ことの確かめにはなっていない

## 12. 確かめたこと・確かめていないこと

確かめたこと。

- カスタムアダプタを動かすコード（`internal/config/config.go` の Cmd）は、環境の変数を指定していない。Go では、指定しなければ親のものを受け継ぐ
- go のアダプタ（`internal/annotation`）に、Skip を扱う所はない
- 画面のコード（`web/src`）に、HTML をそのまま差し込む所はない
- 今の約束リストで、flags のある仕様は 298 件のうち 280 件。用語と機能は 0 件

確かめていないこと。

- 上のほかは、約束リストの文と設定から読み取った。実物で起こしたものは、A-2 の `--base` と、G1〜G4 だけ
- N1 は、実際にカスタムアダプタからトークンを読めるかを、動かして試していない
- 「対策あり」の 24 行も、約束の文があることを見ただけで、わざと逸脱を起こして確かめてはいない
- 行の分け方と判定は、書いた行為者 1 つの見立て。別の行為者には確かめさせていない
