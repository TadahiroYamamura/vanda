# コード

- `panic`、comma-ok なしの型の取り出しのように、エラーを値として返さずに止まる書き方をしない。エラーを返し、呼び出し元で扱う
- エラーのメッセージには、どのファイルの何行目の、何がいけないか、どう直せばよいかを書く
- 新しい依存を足す前に、監督に聞く
- コメントは、なぜこの形なのか（制約、選ばなかった案、直感に反する点）だけを書く。何をしているかは、コードで分かるようにする
