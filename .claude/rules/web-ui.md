# 画面の作り

- 利用者が書いた文（約束の文・条件・理由・推測、用語や機能の定義、ストーリーの題、コミットのメッセージ、人の名前など）は、続いた空白と改行をそのまま出す（`white-space: pre-wrap` と長い語の折り返し）。HTML は何もしなければ、続いた空白を 1 つにまとめ、改行を詰める。差分の中の空白だけの `del`・`ins` も見えるようにする
- 狭い幅で表を縦に並べるなど、見た目のために見出しを隠すときは、`display: none` で消さず、見えなくするだけにする（`visually-hidden`）。消すと読み上げから見出しが消え、見出しで表を探すテストも落ちる
